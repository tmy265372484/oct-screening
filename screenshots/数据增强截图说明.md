# 数据增强截图说明

本组材料用于记录 OCT 分类项目增加温和数据增强的设计过程。**03～05 是修改完成后，在 VS Code 中打开真实代码、修改对比及训练日志补拍的回顾截图，不是修改发生时同步保存的历史截图。06 是根据真实训练图像生成的增强效果样例，不是操作截图或训练效果证明。**

| 文件名 | 内容与用途 |
| --- | --- |
| `03_数据增强代码实现.png` | 展示 `train_resume.py` 中的增强参数及 `build_transforms()` 实现。 |
| `04_数据增强修改对比.png` | 在 VS Code 差异视图中对比旧脚本备份与当前脚本，展示新增的增强配置及独立预处理函数。 |
| `05_增强生效与续训日志.png` | 展示真实 `training.log` 中的增强切换、参数、恢复完整检查点及第 24 轮开始记录。 |
| `06_数据增强效果对照.png` | 每类选择一张真实 OCT 训练图像，调用当前训练增强链生成三个随机样例；第一列是统一预处理后的原图对照。 |

06 的显示图像经过标准化后反归一化，以便观看，并由训练输入尺寸 160×160 放大展示。生成脚本为同目录下的 `generate_augmentation_preview.py`；配套 `06_数据增强效果对照.json` 记录增强参数、图像选择规则、随机种子及 1920×1840 的成图尺寸，便于核查和复现。

实际切换于 **2026 年 10 月 17 日 13:58:19（北京时间）**核验生效，以 `models/torch_resume/augmentation_change.json` 的 `applied_at` 为依据。训练日志在 13:58:17 记录切换到 `mild_oct_v1`，在 13:58:18 记录恢复已完成的第 23 轮并开始第 24 轮。因此，**新增增强从第 24 轮开始使用，目标总轮数仍为 50，并未从零训练。**切换前旧进程已进入第 24 轮的少量批次，这部分未完成进度被舍弃；日志出现两次第 24 轮开始记录，是恢复重跑该轮的结果。

| 训练图像处理 | 修改前 | 修改后 |
| --- | --- | --- |
| 水平翻转 | 概率 50% | 保留，概率 50% |
| 随机旋转 | ±10° | 保留 ±10°，由 `RandomAffine` 实现 |
| 随机平移 | 无 | 水平、垂直方向各不超过图像对应尺寸的 3% |
| 随机缩放 | 无 | 缩放比例 0.97～1.03 |
| 亮度与对比度 | 无额外扰动 | 调整系数各随机取 0.9～1.1 |

仿射变换使用双线性插值，空白区域填充为黑色。输入仍为灰度图复制成 3 通道、调整至 160×160 后标准化。验证集处理保持原样，不加入随机增强；本次未改变网络结构、BatchNorm 训练方式、优化器或学习率策略。

修改前材料保存在 `diagnostics/augmentation_change_20261017_135619/`：`train_resume_before.py` 为旧脚本，`before_latest.pt` 为第 23 轮完整续训检查点，`before_best.pt` 为切换前最佳模型。切换记录文件同时保存了检查点备份的 SHA-256 校验值。

数据增强用于尝试改善泛化表现，**本组截图不证明已经避免过拟合或提高验证准确率**。是否有效，需要结合后续验证准确率、损失和各类别识别指标判断。
