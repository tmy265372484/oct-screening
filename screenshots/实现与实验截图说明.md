## 复现

在项目根目录、已准备可信best.pt的Python环境中：

```powershell
python predict_torch.py --examples --examples-dir assets/demo --device cpu
python grad_cam_torch.py --image assets/demo/CNV.png --device cpu --output-dir outputs/gradcam/cnv_example
python evaluate_torch.py --data-dir data/OCT/test --device cpu
python tools/export_training_summary.py
python tools/export_example_evidence.py
python -m streamlit run streamlit_app.py
```

截图脚本为 `tools/capture_workstation.cjs`，需要额外安装Node.js的Playwright包及Microsoft Edge，在应用运行后执行 `node tools/capture_workstation.cjs`。它打开真实页面、执行分析、下载报告并截图，不注入模拟推理结果。07/08图内的数值均源自可核查的本地记录与推理JSON。

原训练日志、权重和临时推理输出保留在本机，不上传GitHub；仓库中的 `assets/` 只包含脱敏汇总和4张有来源说明的演示切片。03–05是事后回顾截图，具体说明见原文档。

后续完整审计发现验证集303张与训练图完全相同，并有269组相同内容跨类别。新的证据与限制见 `docs/数据审计与误判分析.md`。15、16为训练后补充分析的真实页面截图，不表示已经修复数据或重新训练。案例ID为报告内匿名序号，非患者编号；16中的图像来自同一公开OCT数据来源，署名与来源见 `assets/demo/README.md`。
