# 案例库与健康咨询

2026-10-18 新增。本机服务仍为 http://127.0.0.1:8501/。

## 案例库

每次新分析完成后，事务性写入 outputs/cases.sqlite3。保存时间、类别分数、输入文件名与SHA-256、标准亮度的预览图（最长边1280）、关注叠加图、备注。不会重新推理历史案例，也不将显示预览冒充原始分辨率数据。

列表支持文件名/编号/备注搜索、分类筛选与每页9例。详情支持影像对照、四类分数、备注保存、HTML/文字报告导出和显式确认删除。工作台调整关注图强度或备注后，可点击“保存备注与当前关注图”更新归档。

旧版本只保存在浏览器会话中的案例无法凭空恢复；从此次版本起的新分析自动入库。数据库是本机共享存储，无用户账号隔离或加密。只监听127.0.0.1；部署到公网前需另行实现认证与权限。数据库与图片不提交GitHub。备份时应停止服务再复制数据库文件。

## example 图库

根目录 example/ 支持JPEG/PNG及子文件夹。实际检查时该文件夹不存在，已创建并复制 assets/demo 的四张公开示例，来源见 assets/demo/README.md。队友可自行放入图片，或使用上传入口。目录无图片时显示提示，不伪造输入。

## 健康咨询

按用户选择先实现本地规则问答，不连接大模型API、不上传影像或咨询文本。界面明确标注能力边界；按问题关键词提供一般分类解释、一般治疗方向、就诊准备或紧急症状提醒。关联案例仅提供类别背景，不能据此确诊。不是临床分诊系统，不承诺识别所有风险症状。

对话仅在当前会话中保留最近40条消息；可下载文本或清空。不同关联案例的对话分开，切换案例不会串用前一案例的分类。没有个体处方、剂量、治疗确认或假医生身份。
