# 数据审计与 DRUSEN 错误分析

本次为只读审查，未重新训练、移动、删除或重分数据。扫描109,309张图：train 106,309、val 2,000、test 1,000；无解码错误，全部符合现有类别-数字-切片编号命名格式。

## 主要结论

| 数据对 | 候选患者编号交集 | 字节完全相同内容组 | 原尺寸灰度像素相同内容组 |
|---|---:|---:|---:|
| train / val | 1,079 | 303 | 303 |
| train / test | 0 | 0 | 0 |
| val / test | 0 | 0 | 0 |

验证集有303张与训练图字节相同，占15.15%；对应350张训练图（同一内容可能在训练内重复）。1,993张验证图的候选编号出现在训练中，占99.65%。`prepare_data.py`按图片随机抽取验证集，没有按患者分组。现有验证准确率75.25%不能作为无数据交叉的独立验证证据。

“候选患者编号”指文件名中间数字，缺少患者映射表，不能直接当作经过身份核验的患者。测试与其他划分未发现这些编号或完全重复内容交叉，但没有穷举近似图像、相邻B-scan、重新压缩/裁剪后的近重复，因此不宣称已经完成全面的患者独立性验证。

全数据共有7,092组字节重复内容，涉及14,958张图；原尺寸灰度像素重复为7,117组、15,008张。其中269组相同文件内容跨类别出现，应核验来源与标签，不能自动判定哪一类别正确。详细路径和哈希证据只保存在本机 `outputs/data_audit/duplicate_evidence.json`。

## DRUSEN错误去向

固定使用原best.pt（第18轮），对test中全部250张DRUSEN图进行预测，与已有评估结果一致。

| 预测类别 | 数量 | 占本类 | 模型分数≥90%的数量 |
|---|---:|---:|---:|
| DRUSEN（正确） | 105 | 42.0% | 11 |
| CNV | 80 | 32.0% | 17 |
| NORMAL | 51 | 20.4% | 8 |
| DME | 14 | 5.6% | 0 |

145张误判中，131张被判为CNV或NORMAL，占90.34%。25张误判的模型分数仍≥90%；阈值拒识可以作为后续验证实验，但不能消除全部高分错误。

训练集DRUSEN仅8,116张，占7.63%，NORMAL为50,640张，约6.24倍。类别不平衡是待验证的因素，当前证据不能把全部错误归因于不平衡或过拟合。

报告按每个预测类别的分数降序，选最高分和中间名次各1例，共8例，包含正确对照。每例同时展示原图、预测类别Grad-CAM，以及误判时DRUSEN目标的Grad-CAM。各图独立归一化，不能跨类别按颜色比较数值；关注图不证明病灶、标签错误或具体误判机制。另有4组按哈希排序选取的跨标签重复图样例，供人工复核。

## 后续实验建议

1. 先核验候选患者标识和269组标签冲突，不自动删除或重标。
2. 建立按患者和重复内容连接组隔离的固定划分，保存版本与样本清单。保留当前数据和模型，另建实验目录。
3. 在新划分上重建基线。旧模型已接触旧训练图，不能在重分出的测试图上声称独立性能。
4. 在固定随机种子、划分与训练预算下，分别比较类别加权、最后一组网络层微调和增强强度；一次只改变一项，仅用验证集选择。
5. 当前测试案例已经用于探索错误；最后方案应在未参与开发的留出数据上评估，报告每类召回率、宏F1、混淆矩阵及区间。
