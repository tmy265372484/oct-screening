## 用户流程

上传单张 OCT → 点击开始分析 → 对照原图与模型关注区域 → 查看四类匹配分数 → 填写阅片备注 → 下载报告。

主导航只保留影像工作台、检查记录、使用帮助。首次进入显示上传入口和清晰空状态；体验示例需明确选择，不冒充真实病例。

研发档案移至独立入口 research_app.py，训练曲线、实验结果和审计证据保留在仓库。普通用户不需要挑选检查点、阅读模型训练轮数或实验结论。报告正文移除验证准确率，页脚保留简短分析版本用于追溯。

## 实际能力边界

当前处理 JPEG/PNG 单张切片。没有实现 DICOM 序列、设备接入、患者永久档案、跨次配准、病灶分割或临床签署；因此不展示虚假的病人数量、诊疗状态、测量工具或完成标记。Grad-CAM 称为模型关注区域。

显示亮度、放大、单/双图切换不改变模型输入或结果；报告保留完整视野与标准亮度，叠加强度与当前阅片设置一致。当前会话最多保留5次结果，离开前应导出报告。
