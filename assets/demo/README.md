# OCT 演示切片

这四张图来自项目本地 Kermany2018 / ZhangLab OCT 数据集的 examples 目录，各类按文件名排序取第一张。转换为 PNG、移除原文件名及元数据，使用类别名命名。

来源：Kermany et al., *Identifying Medical Diagnoses and Treatable Diseases by Image-Based Deep Learning*, Cell (2018), DOI: 10.1016/j.cell.2018.02.010。数据说明与使用条件以原始发布页为准：https://data.mendeley.com/datasets/rscbjbr9sj/2 （CC BY 4.0）。

仅用于软件功能演示，类别标签不传入模型；不构成额外的独立测试数据或患者独立的临床验证。未根据预测正确与否筛选图像。其余数据集图像不进入 Git 仓库。
